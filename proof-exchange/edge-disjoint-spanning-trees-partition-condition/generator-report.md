SUGGESTED FILE NAME: edge-disjoint-spanning-trees-partition-condition
FORMAL STATEMENT: Let G=(V,E) be a finite connected (loopless, parallel edges allowed) graph with V nonempty, and k >= 0 an integer. Then G contains k pairwise edge-disjoint spanning trees if and only if for every partition P of V into r >= 1 non-empty sets, the number e_G(P) of edges with endpoints in different parts is at least k(r-1). (Nash-Williams–Tutte theorem; connectivity is not needed.)
DEFINITIONS: Finite multigraph, V nonempty, no loops (loops are irrelevant to both sides and may be deleted); partition parts are non-empty (standard; with empty parts allowed the statement is false, e.g. K_2, k=1, {V, empty}); cross edges counted with multiplicity; the problem's "n" (number of parts) is renamed r; forests/trees identified with edge sets; two parallel edges form a 2-cycle. The theorem is proved self-contained (not cited), using only elementary forest facts (F1)-(F5).
MAIN IDEA: Necessity: every spanning tree must connect all r parts and so uses at least r-1 cross edges. Sufficiency: take k edge-disjoint spanning forests with the maximum total number of edges, and collect all edges that can be made unused by a sequence of edge exchanges. The components of these "freeable" edges form a partition in which every forest is connected inside every part, so all cross edges are forest edges and forest F_i has exactly r - c_i of them (c_i = its number of components). The condition then forces every c_i = 1.
ATTACK PLAN: (1) Necessity via contracting parts: tree induces a connected multigraph on the r parts. (2) Sufficiency: matroid-union route would need the matroid union theorem (not elementary), so use the direct exchange argument (Diestel 2.4): maximum tuple of forests, replacement operation, its reversibility, the set E^ of freeable edges, a lemma that each forest is connected on each component of (V,E^), then exact counting via |forest edges| = |V| - #components.
ATTEMPTS: Necessity, direct counting through quotient multigraph: works. Sufficiency, proof by contradiction with a minimal counterexample (delete an edge): not pursued further, since the condition is not preserved under edge deletion in a controllable way. Sufficiency, exchange argument with maximal forests: works; key subtlety was that the induction over the replacement sequence must be done for a fixed edge e starting from a tuple that misses e, which requires proving that replacements are reversible (Claim 2(c)). Counting step made exact (r - c_i cross edges per forest), so no separate contradiction step is needed; small cases K_4 (k=2, tight), C_4 (k=2, fails), K_2 checked.
